# Probability of a White Christmas — CONUS dashboard

A Python pipeline plus a static dashboard for GitHub Pages. It maps the historical probability of **at least 1 inch of snow on the ground on December 25** across the contiguous U.S., from NOAA NCEI's **1991–2020 U.S. Climate Normals**.

* **Projection:** North America Lambert Conformal Conic, **ESRI:102009** — the same projection as NOAA's interactive map. The pipeline grids in it, the page displays in it (Leaflet + Proj4Leaflet, vendored), and nothing is reprojected in between.
* **Data:** NOAA's public station layer behind that map (`Percent_da`, `ELEVATION`, `Years` per station), with the NCEI spreadsheet as a fallback.
* **Resolution:** a 1 km grid in the map projection. The surface is an inverse-distance-weighted interpolation of the station values; no terrain or other ancillary data is used.
* **Colour:** ColorBrewer **Blues**, 9-class sequential, with a **Light / Dark** toggle. Light: darker = higher chance. Dark: anchor flipped so high chance is near-white (NOAA's own white = >90 % convention).
* **Map:** pannable/zoomable, CONUS-fit on load, click-to-read value (exact, at full grid resolution), station layer, station search, adjustable probability opacity.

```
pipeline/            Python: stations → LCC grid → IDW surface → PNG/JSON
site/                Static page (index.html, app.js, style.css, vendor/)
site/data/           GENERATED by the pipeline (git-ignored)
data/raw/            Cached inputs (station JSON, boundaries)
tests/               pytest — synthetic fixtures only, no network
.github/workflows/   Build + deploy to GitHub Pages
```

## Deploy to GitHub Pages

1. Push this folder to a GitHub repo (default branch `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. Push (or run the workflow manually). It runs the tests, builds `site/data/`, and publishes `site/`.

The page will be at `https://<user>.github.io/<repo>/`. NOAA's inputs change only when new Normals are issued (next ~2031), so there is no schedule; downloads are cached between runs.

## Run locally

```bash
pip install -r requirements.txt
python -m pytest -q
python -m pipeline.build              # downloads inputs, writes site/data/  (a few minutes the first time)
python -m http.server -d site 8000    # open http://localhost:8000
```

Flags: `--source arcgis|xlsx|auto`, `--stations FILE` (local xlsx/csv), `--prob-col "<header>"`, `--refresh`, `--res 1000` (pixel size in metres), `--demo` (**synthetic** stations for previewing offline; the page shows a "DEMO DATA" banner).

`--res 500` matches the finest tiles in NOAA's own service but quadruples memory and file sizes (several GB of RAM, tens of MB of PNG); 1 km is the practical limit for a static page and is already finer than the station network can support.

### If a download is blocked

* NOAA feature layer unreachable → the build falls back to the NCEI spreadsheet. You can also hand-place either input in `data/raw/` (`stations_arcgis.json` or `Christmas_day_snow_statistics_1991-2020_updated.xlsx`); files already there are used without touching the network.
* The spreadsheet loader finds columns by header text. If the layout differs, or two probability columns look equally plausible, it stops and prints every header instead of guessing — re-run with `--prob-col "<exact header>"`.

## Method and caveats

* NOAA publishes **station** probabilities. NOAA's own map surface was interpolated with thin-plate splines and is distributed only as pre-rendered tiles, so it cannot be re-coloured. This project builds its **own** surface from the same station values; do not read it as NOAA's.
* The interpolation is a modelling choice, not an official product. The build prints a leave-one-out error at the stations and the page footer reports it. Between stations, and especially in sparsely sampled mountain areas, the surface is a smooth blend of distant stations and carries no terrain detail.
* Area shares in the dashboard are true-area-weighted (LCC is conformal, not equal-area).
* This is climatology, not a forecast.
