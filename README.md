# Probability of a White Christmas — CONUS dashboard

A static dashboard for GitHub Pages. It shows **NOAA's own map** of the historical probability of **at least 1 inch of snow on the ground on December 25** (1991–2020 U.S. Climate Normals, NOAA NCEI), plus the station values behind it.

* **Map:** NOAA's cached ArcGIS map service, [`Christmas_Snow_2020normals_Lambert_update`](https://tiles.arcgis.com/tiles/C8EMgrsFcRFL6LrL/arcgis/rest/services/Christmas_Snow_2020normals_Lambert_update/MapServer), drawn by Leaflet in the service's **own tile grid and projection** (North America Lambert Conformal Conic, ESRI:102009), so what you see is NOAA's rendering, not a re-creation. Pannable and zoomable over the whole CONUS. NOAA publishes five zoom levels (finest ≈ 500 m/pixel); the page allows one extra step of overzoom.
* **Stations:** NOAA's public station layer behind that map (`Percent_da`, `ELEVATION`, `Years`), with the NCEI spreadsheet as a fallback. Used for the station dots (toggle them on the map or in the toolbar), search, click look-up ("nearest station"), the headline figures, and the "Stations by chance" table, which recalculates for whatever part of the map is in view. These figures are shares of **stations**, not land area.
* **Legend:** NOAA's eight classes (0–10, 11–25, 26–40, 41–50, 51–60, 61–75, 76–90, 91–100 %). Swatch colours were sampled from NOAA's interactive-map legend and checked against the rendered tiles; edit `NOAA_COLORS` in `pipeline/config.py` if they ever differ.
* **Light / Dark toggle:** changes the page, overlays and station markers. NOAA's tiles keep NOAA's colours in both themes (they are pre-rendered images).
* **Optional overlays** (off by default): state lines and place labels from Natural Earth, in case you want them on top of NOAA's tiles.

```
pipeline/            Python: station table -> stations.json/csv + meta.json (+ optional overlay vectors)
site/                Static page (index.html, app.js, style.css, vendor/)
site/data/           GENERATED by the pipeline (git-ignored)
data/raw/            Cached inputs (station JSON, boundaries)
tests/               pytest — synthetic fixtures only, no network
.github/workflows/   Build + deploy to GitHub Pages
```

## Deploy to GitHub Pages

1. Push this folder to a GitHub repo (default branch `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. Push (or run the workflow manually). It runs the tests, builds `site/data/`, and publishes `site/`.

The page will be at `https://<user>.github.io/<repo>/`. NOAA's inputs change only when new Normals are issued (next ~2031), so there is no schedule; downloads are cached between runs. The tiles are requested live from NOAA by each visitor's browser.

## Run locally

```bash
pip install -r requirements.txt
python -m pytest -q
python -m pipeline.build              # downloads the station table, writes site/data/
python -m http.server -d site 8000    # open http://localhost:8000
```

Flags: `--source arcgis|xlsx|auto`, `--stations FILE` (local xlsx/csv), `--prob-col "<header>"`, `--refresh`, `--no-overlays`, `--demo` (**synthetic** stations for previewing offline; the page shows a "DEMO DATA" banner).

### If a download is blocked

* NOAA feature layer unreachable → the build falls back to the NCEI spreadsheet; if both fail it prints both reasons. A download that is not really an Excel file (e.g. an HTML error page) is rejected and never cached. You can also hand-place either input in `data/raw/` (`stations_arcgis.json` or `Christmas_day_snow_statistics_1991-2020_updated.xlsx`); files already there are used without touching the network.
* The spreadsheet loader finds columns by header text. If the layout differs, or two probability columns look equally plausible, it stops and prints every header instead of guessing — re-run with `--prob-col "<exact header>"`.
* Natural Earth overlays are optional: if they can't be downloaded the build still succeeds and the overlay checkboxes are disabled.

## Caveats

* The map is only as available as NOAA's tile service; if it is down the page shows the stations and legend without a surface.
* A click reports the **nearest station**, not an interpolated value: NOAA does not publish the surface as data, only as pre-rendered tiles.
* Climatology is not a forecast.
